Koala Slideshow Generator

README and user guide

What it does

Koala Slideshow Generator creates a Commodore 64 program called SLIDESHOW.PRG. The program loads and displays a sequence of Koala Painter images from a disk drive.

Each image can use its own border colour, display time and advance mode. Images may advance automatically, by keypress, or by whichever happens first. The slideshow can loop back to the first image or remain on the final image.

The generator runs entirely in your web browser. It does not upload your images anywhere.

Requirements

  • A modern web browser.
  • One or more Koala image files in .kla or .koa format.
  • A tool such as DirMaster for creating or editing a D64 disk image.
  • A real Commodore 64, an Ultimate device, or a compatible emulator.

Image conversion: Programs such as RetroPaint can convert ordinary image files to Koala format.

How to use it

  1. Open the Koala Slideshow Generator HTML file in your browser.
  2. Choose the drive number. For most setups this will be drive 8.
  3. Set the default advance mode and duration. These values are used when new images are added.
  4. Choose what should happen after the final image: loop to the first image or remain on the final image.
  5. Click + Add image and select one or more Koala files.
  6. Check the preview for each image and adjust its border colour, advance mode and duration.
  7. Use the up and down buttons to change the image order. Use Delete to remove an image.
  8. Click Generate SLIDESHOW.PRG.
  9. Create or open a D64 image in DirMaster.
  10. Copy SLIDESHOW.PRG and all the selected Koala files to the same D64 image.
  11. Save the D64 image, mount it on the C64 or emulator, and run the slideshow with LOAD"SLIDESHOW",8,1 followed by RUN.

Slideshow settings

Drive numberThe device number used when the slideshow loads each image. Normally 8.
Default advance modeDetermines the initial mode assigned to newly added images.
Default durationThe initial number of seconds used for newly added timed images.
After final imageChoose whether the slideshow loops or stays on the last image.
Border colourThe C64 border colour used while the selected image is displayed.
Advance modeTimer or keypress advances after the selected time or immediately when a key is pressed. Keypress only waits indefinitely.

Important filename rules

The generator removes the .kla or .koa extension and converts the filename to lowercase. The resulting C64 filename may contain no more than 16 characters.

For example:

image01.kla becomes image01.

The file must appear on the D64 image under that same C64 filename. Do not add the .kla extension to the filename stored on the disk image.

Do not change filenames after generating the PRG. If an image is renamed on the D64 image, the slideshow will no longer be able to load it. Generate a new SLIDESHOW.PRG after changing filenames or image order.

Koala file handling

The selected Koala files are used only for validation and preview inside the browser. They are not embedded in SLIDESHOW.PRG.

You must therefore copy every Koala file to the D64 image yourself. All slideshow files must be available on the selected C64 drive when the program runs.

The program loads the next image while the current Koala image remains visible. A small loading symbol appears in the lower-right corner during disk access.

Troubleshooting

The border turns red and the slideshow stops

This indicates that the C64 could not load the requested image. Check that:

  • The Koala file is present on the same D64 image as SLIDESHOW.PRG.
  • The filename on the D64 image matches the filename shown in the generator.
  • The filename does not include the host extension .kla or .koa.
  • The correct drive number was selected.
  • The disk image is mounted and accessible.

The preview is missing or rejected

Make sure the selected file is a valid Koala image. Renaming another file type to .kla does not convert it.

The slideshow loads the wrong image

Check for duplicate or truncated filenames. C64 filenames are limited to 16 characters.

Disk contents example

0 "KOALA SHOW" 00 2A 10 "SLIDESHOW" PRG 40 "PERSON" PRG 40 "WOMAN" PRG 40 "MAN" PRG 40 "CAMERA" PRG 40 "TV" PRG BLOCKS FREE.

DirMaster and C64 directory listings may display filenames using uppercase screen characters. This does not mean that you should enter uppercase letters in the generator.

Limitations

  • A maximum of 64 images is supported.
  • Each filename is limited to 16 characters. Please only use valid c64 filename characters.
  • The image files are not packed into the generated PRG.
  • The generator does not create D64 images.
  • Timed playback is designed for PAL timing.

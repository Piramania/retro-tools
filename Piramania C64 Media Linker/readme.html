Piramania C64 Media Linker

Piramania C64 Media Linker is a browser-based tool that creates self-contained Commodore 64 intro screens from Koala Painter images and optional SID music.

The generated program can either act as a standalone presentation or as a loader that launches another program when the user presses SPACE.

Typical uses include:

  • Crack intros
  • Game splash screens
  • Disk menu intros
  • Slideshows
  • Demo productions
  • Presentations that load another PRG
  • Multi-part productions

No installation is required. Simply open the HTML file in a modern web browser.

Features

  • Native Koala Painter (.KLA/.KOA) support
  • Optional SID music
  • Optional hardware scrolltext
  • Optional "Press SPACE to continue" loader
  • Automatic VIC-II memory bank selection
  • Automatic SID collision detection
  • Configurable border colour
  • Configurable scroll background colour
  • Configurable scroll text colour
  • Real-time C64 preview
  • Generates a ready-to-run PRG

Requirements

Input image:

  • Koala Painter (.KLA or .KOA)

Optional:

  • PSID/RSID music file
  • Name of another PRG to be loaded from device 8

How it works

1. Load a Koala image

Select a Koala Painter image.

The image is displayed exactly as it will appear on a Commodore 64.

2. Optional: Load a SID file

Load a SID music file.

The Media Linker automatically:

  • parses the SID header
  • detects load, init and play addresses
  • selects a suitable VIC-II memory bank
  • warns if memory conflicts are detected

3. Configure appearance

You can customise:

  • Border colour
  • Scroll background colour
  • Scroll text colour

Border and scroll background may optionally be linked together.

4. Add scrolltext (optional)

If the scroll text field is left empty, no scroller is generated.

If text is entered:

  • the scroller automatically starts off-screen
  • smooth hardware scrolling is enabled
  • the last 8 pixel rows of the image become the scroll area

5. Load another program (optional)

Enable:

Load another file with SPACE

Then enter the filename without .PRG.

Example:

GAME

When SPACE is pressed, the generated intro loads:

GAME

from device 8.

This makes it easy to create:

  • game intros
  • slideshow presentations
  • demo part linkers
  • menu systems

Slideshows

Creating a slideshow is simple.

Create one intro PRG for each picture.

Example:

PART1
PART2
PART3
PART4

Configure:

PART1 loads PART2
PART2 loads PART3
PART3 loads PART4

The result is a slideshow where each screen advances with a press of the SPACE bar.

Memory management

The Media Linker automatically places:

  • bitmap
  • screen RAM
  • colour RAM
  • SID data
  • scroll text

into suitable memory locations. It attempts to avoid collisions between video memory and SID data automatically.

Notes

  • The scroll area uses the bottom 8 pixel rows of the image.
  • Koala images remain completely unchanged except for the scroll area when enabled.
  • SID playback supports both raster and CIA timer playback.
  • Programs are generated as standard C64 PRG files.
